# 集成子琪扩展

`fork` 分支将当前引擎与子琪电脑版懒人包的十一项扩展一起构建。扩展默认开启。`应用配置` 和 `拖拽读取` 依赖 Electron，只在桌面环境加载，浏览器和手机跳过这两项。

## 来源与目录

源码快照来自用户提供的 `★无名杀子琪懒人包v1.11.6.1电脑版.zip`，叠加 `●子琪更新包1.11.6.1新`。完整包 SHA-256、文件哈希和扩展列表记录在 `vendor/ziqi/manifest.json`，各扩展原有作者信息、说明和许可证保持在其目录中。

`vendor/ziqi/runtime/extension` 包含十周年UI、天庭、全能搜索、斗转星移、千幻聆音、皮肤切换、奇妙工具、自用美化、懒人包、应用配置、拖拽读取。其余 `audio`、`image`、`font`、`layout`、`theme` 目录只提供原引擎缺少的补充素材。未包含另行下载的 36G 皮肤、动皮和语音整合包。

扩展与素材直接随 Git 跟踪，构建无需访问网盘或原用户电脑。将作者文件放在独立 vendor 目录，便于同步上游时审查覆盖范围。基础引擎目录仍由上游维护。

## 构建

```sh
pnpm install --frozen-lockfile
pnpm version:check
pnpm test:distribution
pnpm build
pnpm -F @noname/electron build:win
```

仅生成可运行的 Windows 目录时，使用 `pnpm -F @noname/electron build:unpacked`，产物位于 `output/win-unpacked`。设置 `NONAME_DATA_HOME` 可将桌面配置、缓存和日志放入独立目录，默认位置仍是应用内 `Home`。

核心构建在编译后调用 `scripts/bundle-extensions.mjs`。脚本核对每个文件的 SHA-256，将扩展覆盖到运行目录。补充音画若已经存在于上游源码中，则保留上游版本。完整包先复制基础音画，再合并核心输出，防止旧扩展覆盖已适配版本。

全能搜索的 API 文档使用构建环境安装的 TypeScript 编译器和当前引擎类型声明。构建将它们放入运行包，不将工作区 node_modules 提交至 Git。桌面依赖通过 Electron package.json 和锁文件安装。

更新扩展快照时，同步更新 `vendor/ziqi/manifest.json` 中对应路径的字节数和 SHA-256。新增或删除默认扩展还需要更新 `apps/core/noname/util/bundled-extensions.js` 与 `game/config.json`。构建校验失败时修复来源差异，不绕过哈希检查。

部分扩展保留了作者自己的 `.gitignore`，会忽略动态资源目录。新增素材确认属于清单后，对相应路径使用 `git add -f`，避免遗漏资源。构建会校验清单中的文件是否齐全。

## 兼容修改

- 天庭的文件立绘识别兼容引擎文件服务。
- 懒人包恢复设置只合并外观，保留 fork 更新渠道和联机配置。版本变更不会自动覆盖整个配置文件。
- 懒人包将大厅鉴权失败消息交还 fork 处理，昵称输入使用引擎异步输入框。
- 身份模式保留旧候选数量并补齐各身份独立字段，避免斗转星移为 AI 生成空候选。
- 千幻聆音适配牌语音接口的玩家对象和性别字符串参数。
- 全能搜索补齐文档依赖，并处理异步生成失败。
- 十周年跟随动画等待池中全部播放器加载资源，避免只加载第一个播放器就宣告就绪，在快速连续播放时出现骨骼未加载错误。
- 正式 Electron preload 提供以游戏根目录为基准的 require 和 \_\_dirname，保留原桌面菜单与窗口行为。

## 验证边界

本地预览已实测十一项扩展初始化、手动选将、八人牌局回合推进、搜索、静态皮肤设置与重载保存，以及阿里云大厅的错误密钥拒绝、正确密钥登录和刷新重连。测试使用独立配置，没有操作文件导入、系统协议注册和外链。未穷举所有技能、模式或多人完整对局。

正式仓库构建的 Windows 运行目录也完成了上述桌面检查，并验证四个动画播放器的就绪回调。记录见 [桌面集成验证](./verification/desktop-1.11.7-c3nhx.1.json)。NSIS 安装程序、Android 和 iOS 原生包未在本次本机检查中构建。

原作者包缺少部分可选皮肤配置、十周年装饰图和卡面，相关资源请求可能返回 404。模式加载也会先探测目录入口，再回退至打包后的单文件。这些请求记录不能替代对具体功能的验证。
